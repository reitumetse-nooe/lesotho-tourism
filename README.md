# Discover Lesotho

## About the Project
Discover Lesotho is a tourism website that showcases beautiful tourist attractions and activities in Lesotho.

## Features
- Home page
- Tourist attractions
- Search and filter attractions
- Popular activities
- Enquiry form

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
